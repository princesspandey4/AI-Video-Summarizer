# AI Video Summarizer 🎥🤖

An AI-powered web application that converts video content into useful summaries, transcripts, notes, PDFs, and answers to questions.

## 🚀 Features

- 🎙️ Video transcription
- 📝 AI-powered video summarization
- 📚 Automatic notes generation
- 📄 PDF generation
- ❓ Question & Answer from video content
- 🌐 Simple and user-friendly web interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- AI / Generative AI
- Video & Audio Processing
